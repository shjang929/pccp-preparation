# PCCP 준비 기록

플레이데이터 SK네트웍스 Family AI 캠프 36기 과정 중 PCCP(프로그래머스 코딩전문역량인증)를 준비하며 정리한 학습 노트입니다.  
교재는 박경록 님의 『코딩 테스트 합격자 되기』 파이썬 편을 사용합니다.

## 목차

| 회차 | 주제 | 핵심 내용 | 자료구조 / 알고리즘 | 시간 복잡도 |
|------|------|-----------|---------------------|-------------|
| [PCCP 준비(1)](./PCCP준비_01.md) | 알고리즘의 효율 분석 | 시간 복잡도, 빅오 표기법, 함수의 증가 추이 | 효율 분석 | - |
| [PCCP 준비(2)](./pccp-02-stock-price.md) | 문제 12 주식 가격 (11주차 회고) | 스택으로 가격이 떨어지지 않은 기간 구하기, 두 while문의 역할 | 스택 | O(N) |
| [PCCP 준비(3)](./pccp준비_03.md) | 문제 13 크레인 인형 뽑기 게임 (12주차 회고) | 열별 스택 구성, 인형 뽑기와 바구니 처리, 같은 인형 제거, 코드 실행 과정 분석 | 스택 / 시뮬레이션 | O(N² + M) |
